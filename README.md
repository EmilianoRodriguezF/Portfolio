# Emiliano Rodriguez — Portfolio Website

Static website (no build step). Open `index.html` to view it locally.
Note: the YouTube videos only play on the live (https) site, not when opened as a local file.

## Pages
- `index.html` — Home
- `projects.html` — Projects gallery
- `resume.html` — Resume page (the PDF lives in `assets/`)
- `vehicle.html`, `boat.html`, `heating-element.html`, `packaging-line.html` — project pages

## Where things are
- `css/` — one stylesheet per page
- `js/` — one script per page
- `assets/img/` — photos and diagrams
- `assets/video/` — short looping videos
- `assets/Emiliano_Rodriguez_Resume.pdf` — resume PDF used by the Resume buttons

## Replacing the resume later
Upload a new PDF named exactly `Emiliano_Rodriguez_Resume.pdf` into the `assets` folder (replace the old one).
